# 要件定義書

## プロジェクト概要

| 項目 | 内容 |
|------|------|
| プロジェクト名 | AIチャットボット |
| 目的 | 参加講座の最終課題として、AIチャットボットを開発する |
| 提出期限 | 2026年2月15日 23:59（厳守） |
| 提出物 | AIチャットボットの動作動画（約1分間） |

## 機能要件

### 必須機能（Must Have）

| ID | 機能名 | 説明 | 優先度 |
|----|--------|------|--------|
| F-001 | 基本チャット機能 | ユーザーからのテキスト入力に対してAIが応答する | 高 |
| F-002 | Webチャットインターフェース | ブラウザ上で動作するチャットUI | 高 |
| F-003 | Gemini API連携 | Google Gemini APIを使用したLLM応答生成 | 高 |

### 推奨機能（Should Have）

| ID | 機能名 | 説明 | 優先度 |
|----|--------|------|--------|
| F-004 | ファイル参照機能（RAG） | 外部ドキュメントを参照して回答を生成 | 中 |
| F-005 | 知識ベース統合 | ブリッジ講座内容をナレッジとして活用 | 中 |
| F-006 | 会話履歴管理 | 過去のやり取りを考慮した応答生成 | 中 |

### 追加機能（Could Have）

| ID | 機能名 | 説明 | 優先度 |
|----|--------|------|--------|
| F-007 | マルチターン会話 | 文脈を維持した複数回のやり取り | 低 |
| F-008 | レスポンス速度最適化 | ストリーミング応答の実装 | 低 |

## 非機能要件

### パフォーマンス要件

| 項目 | 要件 |
|------|------|
| 応答時間 | 初回応答まで5秒以内 |
| 同時接続数 | 1（ローカル実行のため） |

### 運用要件

| 項目 | 要件 |
|------|------|
| 実行環境 | ローカル環境（動画撮影用） |
| ブラウザ対応 | Chrome, Firefox, Safari（最新版） |

### セキュリティ要件

| 項目 | 要件 |
|------|------|
| APIキー管理 | 環境変数での管理（コードに直接記載しない） |
| 入力検証 | XSS対策、インジェクション対策 |

## 技術スタック

### 必須技術

| カテゴリ | 技術 | 理由 |
|----------|------|------|
| LLM API | Gemini API | 無料枠が利用可能、講義推奨 |
| UI | Webベース | 汎用性・デモのしやすさ |
| 実行環境 | ローカル | 動画撮影用 |

### 検討技術

| カテゴリ | 候補 | 備考 |
|----------|------|------|
| フレームワーク | Dify / Streamlit / Next.js | 講義資料から選定 |
| デプロイ | Vercel（Hobbyプラン） | 無料枠利用可能 |

## 成功基準

1. **最低限の修了要件**: 基本的なチャット機能が動作し、動画で確認できる
2. **表彰対象の条件**: 独自の工夫（RAG機能、UI/UXの改善など）が認められる

## 制約事項

- Gemini APIの無料枠内での利用
- 提出期限の厳守
- 動画内に講座関連の質問を含める必要がある

## 用語定義

| 用語 | 定義 |
|------|------|
| RAG | Retrieval-Augmented Generation。外部知識を検索・参照して回答を生成する手法 |
| LLM | Large Language Model。大規模言語モデル |
| Gemini API | Googleが提供するLLM API |
