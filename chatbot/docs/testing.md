# テスト仕様書

## 概要

本ドキュメントでは、AIチャットボットシステムのテスト計画・テストケースを定義する。

## テスト方針

### テストレベル

| レベル | 目的 | 担当 |
|--------|------|------|
| ユニットテスト | 個々のモジュールの動作確認 | 開発者 |
| 統合テスト | モジュール間連携の確認 | 開発者 |
| E2Eテスト | ユーザーシナリオの確認 | 開発者 |
| 受け入れテスト | 要件充足の確認 | 開発者 |

### テストツール

| テスト種別 | ツール |
|-----------|--------|
| Pythonユニットテスト | pytest |
| モック | pytest-mock, unittest.mock |
| APIテスト | httpx, pytest-asyncio |
| E2Eテスト | Playwright / Selenium |
| カバレッジ | pytest-cov |

    page.fill("textarea", "こんにちは")

    page.wait_for_selector(".assistant-message")

## テスト実行コマンド

```bash
# ユニットテスト実行
pytest tests/unit/ -v

# 統合テスト実行
pytest tests/integration/ -v

# E2Eテスト実行
pytest tests/e2e/ -v

# 全テスト実行（カバレッジ付き）
pytest --cov=src --cov-report=html

# 特定のテストのみ実行
pytest -k "test_generate_response" -v
```
