# テスト仕様書

## 概要

本ドキュメントでは、AIチャットボットシステムのテスト計画・テストケースを定義する。

## テスト戦略

### 品質ゲート方式

本プロジェクトでは「品質ゲート方式」を採用し、各フェーズで次のフェーズの品質を担保する。

```
┌─────────────────────────────────────────────────────────────────────┐
│  Phase 1: 基盤品質                                                   │
│  ┌─────────────────────────────────────────────────────────────┐   │
│  │ ユニットテスト                                               │   │
│  │ ・LLM Client正常動作 → API連携品質を担保                    │   │
│  │ ・RAG各モジュール動作 → 知識ベース品質を担保                │   │
│  └─────────────────────────────────────────────────────────────┘   │
│                              ↓ Gate 1: 全テストPass                 │
├─────────────────────────────────────────────────────────────────────┤
│  Phase 2: 連携品質                                                   │
│  ┌─────────────────────────────────────────────────────────────┐   │
│  │ 統合テスト                                                   │   │
│  │ ・API正常応答 → E2Eフロー品質を担保                         │   │
│  │ ・RAG知識ベース検証 → 回答品質を担保 ★早期検証             │   │
│  └─────────────────────────────────────────────────────────────┘   │
│                              ↓ Gate 2: 全テストPass                 │
├─────────────────────────────────────────────────────────────────────┤
│  Phase 3: シナリオ品質                                               │
│  ┌─────────────────────────────────────────────────────────────┐   │
│  │ E2Eテスト + 回答品質テスト                                   │   │
│  │ ・ユーザーフロー確認                                         │   │
│  │ ・講座内容回答品質テスト ★ここで本番想定の検証              │   │
│  └─────────────────────────────────────────────────────────────┘   │
│                              ↓ Gate 3: 全テストPass                 │
├─────────────────────────────────────────────────────────────────────┤
│  Phase 4: 最終確認                                                   │
│  ┌─────────────────────────────────────────────────────────────┐   │
│  │ 受け入れテスト（確認のみ、ここで新規問題は発生しない想定）   │   │
│  └─────────────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────────────┘
```

### テストレベルとトレーサビリティ

| レベル | 目的 | 担保する品質 | 失敗時の手戻り |
|--------|------|-------------|---------------|
| ユニットテスト | 個々のモジュール動作確認 | 統合テストの前提条件 | 小（該当モジュールのみ） |
| 統合テスト | モジュール間連携 + **知識ベース品質** | E2E品質の前提条件 | 中（API層まで） |
| E2Eテスト | ユーザーシナリオ + **回答品質** | 受け入れ条件 | 中（UI層まで） |
| 受け入れテスト | 要件充足の最終確認 | - | 発生しない想定 |

### テストツール（Next.js + TypeScript）

| テスト種別 | ツール |
|-----------|--------|
| ユニットテスト | Jest + @testing-library/react |
| APIテスト | Jest + supertest |
| E2Eテスト | Playwright |
| カバレッジ | Jest --coverage |

## テスト実行順序とゲート

```bash
# Gate 1: ユニットテスト
npm test -- --testPathPattern="unit"
# 全Pass → Gate 2へ

# Gate 2: 統合テスト（知識ベース品質含む）
npm test -- --testPathPattern="integration"
# 全Pass → Gate 3へ

# Gate 3: E2E + 回答品質テスト
npm run test:e2e
# 全Pass → Gate 4へ

# Gate 4: 受け入れテスト（確認のみ）
npm run test:acceptance
```
