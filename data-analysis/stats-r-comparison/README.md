# 統計分析（R比較）

R言語の記事を参考に、Pythonで同様の統計分析を行う習作です。

## 概要

NBAデータを使用した統計モデルの実験です。
Rで行われている分析手法をPythonで再現しています。

## 機能

- NBAデータの統計分析
- 統計モデルの適用
- Python vs R の手法比較

## 必要な環境

- Python 3.8+
- Google Cloud DataLab または Jupyter Notebook

## 依存ライブラリ

```
pandas
numpy
scipy
statsmodels
```

## 使い方

1. ノートブックを開く
2. 必要に応じてデータをダウンロード
3. セルを順番に実行
