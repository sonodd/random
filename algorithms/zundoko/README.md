# ズンドコキヨシ

> **Note**: このプロジェクトは未実装です。Notebookファイルは破損していたため削除されました。

「ズンドコキヨシ」問題の実装実験です。

## 概要

「ズン」と「ドコ」をランダムに出力し、「ズン」「ズン」「ズン」「ズン」「ドコ」の順番が出たら「キ・ヨ・シ！」と出力するプログラムです。

## ルール

1. 「ズン」または「ドコ」をランダムに出力
2. 「ズンズンズンズンドコ」の並びが出たら「キ・ヨ・シ！」と出力して終了
